# Darshita Vaghela — Developer Portfolio

A responsive personal portfolio for Darshita Vaghela, using a consistent dark plum background with warm light text and coral accents. It presents her full-stack and Python experience, Django, backend services, databases, selected projects, and current Per Scholas AI-Native Software Development training.

## Run locally

Open `index.html` in a browser. This version uses plain HTML, CSS, and JavaScript, so it does not need a build step.

## Before publishing

- Review the contact details, experience descriptions, and skill list before publishing.
- Add a downloadable resume link if you want visitors to access the full resume.
- Review the project descriptions and skills to make sure they reflect your experience.
